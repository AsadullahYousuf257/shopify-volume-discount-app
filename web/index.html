Change the Checkout Message (Module 2)

Each store can show the discount message in its own language. To set a custom message:

  1. Go to Discounts in your Shopify Admin
  2. Click on Anodyne Tiered Discount
  3. Scroll down to the Metafields section
  4. Edit the Discount Message field with your text
  5. Click Save
If no custom message is set, the app will automatically use the correct language based on the store's locale (Danish, Finnish, French, Dutch, German, English, Swedish, Norwegian).

Configure Gift Products (once per store)

Each store chooses its own gift products. Complete these steps once per store:

Step 1 — Find the Variant ID of your gift product

  1. Go to Products in your Shopify Admin
  2. Open the product you want to give as a free gift
  3. Click on the specific variant (colour, size, etc.)
  4. Look at the browser URL — it ends with /variants/12345678901
  5. Your full Variant ID is: gid://shopify/ProductVariant/12345678901

Step 2 — Create the metafield definitions on your Shop

  1. Go to Settings → Custom data → Shops in your Shopify Admin
  2. Click Add definition and create these two metafields:
Book gift product: Namespace: anodyne_gifts  ·  Key: book_gift_variant_id  ·  Type: Single line text
Posture shirt gift product: Namespace: anodyne_gifts  ·  Key: posture_gift_variant_id  ·  Type: Single line text

Step 3 — Set the values

  1. Go to Settings → Custom data → Shops, then click your shop name
  2. Find the two new metafields and paste in the Variant IDs from Step 1
  3. Click Save
The Variant ID must be in full GID format: gid://shopify/ProductVariant/XXXXXXXXXXXXXXX
If a metafield is left empty, that gift will simply not be added — the other tag's gift still works normally.
